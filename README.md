\# EvidenceLens



EvidenceLens is an AI-powered biomedical claim investigation platform.



It examines breast cancer claims across scientific papers, organizes supporting

and conflicting evidence, provides traceable citations, and validates selected

gene-expression claims using a public biological dataset.



\## Current Status



The project foundation is complete:



\- React and TypeScript frontend

\- Python and FastAPI backend

\- Frontend-to-backend health check

\- Initial project scope and product flow



\## Planned MVP



\- Investigate biomedical claims

\- Retrieve relevant scientific evidence

\- Classify studies as supporting, contradicting, unclear, or not applicable

\- Display exact evidence passages and citations

\- Compare study populations, methods, findings, and limitations

\- Validate selected claims against gene-expression data

\- Display statistical results and biological visualizations
