# EvidenceLens Product Flow

## Primary User Journey

1. The user enters a biomedical claim.
2. EvidenceLens searches the paper collection.
3. The system classifies studies as supporting, contradicting, unclear, or not applicable.
4. The user inspects exact evidence passages and citations.
5. The user compares selected studies.
6. The system checks supported gene-expression claims against a public dataset.
7. The user receives a cautious conclusion comparing literature and data.

## Main Screens

### 1. Investigate a Claim

- Claim input
- Optional gene selection
- Example claims
- Investigate button
- Research-use disclaimer

### 2. Evidence Results

- Original claim
- Evidence summary
- Supporting studies
- Contradicting studies
- Unclear studies
- Exact evidence passages
- Classification explanations
- Links to original papers

### 3. Compare Studies

- Study selection
- Population
- Sample size
- Biological material
- Research method
- Main finding
- Limitation
- Evidence classification

### 4. Dataset Validation

- Selected gene
- Tumor versus normal visualization
- Sample counts
- Summary statistics
- Statistical test
- Effect size
- Dataset interpretation
- Literature-versus-data conclusion

## Secondary Screens

- Paper Library
- Paper Details
- About and Methodology

## Final User Outcome

The user receives a traceable conclusion showing what the literature reports,
what the biological dataset shows, where the evidence disagrees, and where
every result originated.
